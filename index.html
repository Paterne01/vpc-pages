Publiez vos vidéos sur TikTok, Facebook et YouTube
automatiquement, chaque jour

« opencode auto post vpc » est l'outil officiel de la page Voix de Prospérité en Christ. Il génère et programme les publications quotidiennes (déclarations, enseignements, vidéos courtes) et les envoie sur vos plateformes sans intervention manuelle.

Télécharger l'application Voir comment ça marche

Gratuit · Installation locale · Votre contenu reste sur votre ordinateur

Pourquoi utiliser cette application ?

Un seul outil pour maintenir une présence quotidienne sur trois plateformes, sans y passer des heures.

📅

Planification automatique

Les publications partent aux créneaux que vous avez définis (matin, midi, soir) : plus besoin d'être présent pour poster.

📱

3 plateformes en une fois

Le même contenu est adapté et envoyé sur TikTok (Content Posting API), Facebook (Reels & images) et YouTube (vidéos).

🔑

Contenu de marque

Vidéos courtes avec fonds, textes bibliques, légendes et appels à l'action générés selon vos formats préférés.

🛠️

100 % local

Application de bureau installée sur votre PC : les textes, images et vidéos sont générés et stockés sur votre machine.

🔒

Sécurité des accès

Vos jetons OAuth sont chiffrés dans le gestionnaire de secrets de Windows. Jamais de clé en clair dans les fichiers du projet.

📊

Panneau de contrôle

Suivez les publications en attente, en échec ou en brouillon, et reprenez-les en un clic depuis l'interface locale.

Comment ça marche en 4 étapes

Le flux complet, de la génération du contenu à la publication sur votre profil TikTok.

Connectez vos comptes

Vous autorisez une seule fois l'accès à vos pages via le flux OAuth officiel de chaque plateforme (TikTok, Facebook, YouTube).

Définissez vos formats et créneaux

Choisissez les types de publications (déclaration, vidéo courte) et les heures de diffusion quotidiennes.

L'application génère le contenu

À chaque créneau, elle prépare le texte, l'image ou la vidéo selon vos formats, puis téléverse et finalise la publication.

Vos vidéos sont en ligne

Vous retrouvez chaque publication sur votre profil TikTok (et Facebook/YouTube) à l'heure prévue. Le panneau de contrôle garde l'historique.

Détail du fonctionnement

Intégrations officielles

L'application utilise les API officielles des plateformes, avec votre autorisation explicite.

TikTok

Publication directe via la Content Posting API (Direct Post), après connexion OAuth sur votre propre compte.

Content Posting API video.publish user.info.basic

Facebook

Publication des Reels et des images sur votre Page, via l'API Graph officielle.

API Graph

YouTube

Téléversement des vidéos sur votre chaîne (youtube-uploader officiel).

YouTube Data API

Téléchargement

L'application s'installe en quelques minutes sur Windows. Le code source est ouvert et disponible sur GitHub.
