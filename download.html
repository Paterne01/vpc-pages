Téléchargement et installation

L'application s'installe en local sur Windows. Le code source est public : vous pouvez aussi l'exécuter directement depuis le dépôt GitHub.

🞃️ Prérequis système

ÉlémentRequis
SystèmeWindows 10 / 11 (64 bits)
Python3.10 ou plus récent
Espace disque500 Mo (médiathèque incluse)
ConnexionInternet (API TikTok, Facebook, YouTube, Gemini)

⭐ Méthode recommandée

Installez l'environnement et les dépendances en une commande, puis lancez l'application.

git clone https://github.com/Paterne01/voix-de-prosperite-en-christ.git
cd voix-de-prosperite-en-christ
install.bat

Le script install.bat crée l'environnement virtuel, installe les dépendances (requirements.txt) et affiche les prochaines étapes.

🔔 Démarrage

Une fois installé, lancez le serveur local et ouvrez le tableau de bord dans votre navigateur.

start.bat

Le tableau de bord est disponible à l'adresse http://localhost:5000.

Le code source complet est disponible sur : github.com/Paterne01/voix-de-prosperite-en-christ

📷 Connexion des plateformes

Dans l'interface locale :

  1. Créez votre fichier config.json à partir de config.example.json.
  2. Ajoutez vos secrets dans .env (copie de .env.example) ou via le trousseau Windows.
  3. Autorisez TikTok, Facebook et YouTube une première fois (OAuth).
  4. Définissez vos formats et créneaux, puis activez la publication.
