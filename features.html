Fonctionnalités

Un aperçu complet de ce que fait l'application pour gérer vos publications quotidiennes sur trois plateformes.

⏱️

Planificateur intégré

Créneaux quotidiens configurables (par défaut 00h, 08h, 12h, 16h) avec rattrapage automatique en cas de coupure : si un créneau est manqué, il est rejoué sans doublon.

📚

Formats de contenu réutilisables

Définissez des « formats » (déclaration, vidéo courte…) avec leur prompt, leurs heures, leurs réseaux et leur tier. La logique réutilisée est partagée entre le planificateur et le lancement manuel.

🖦

Panneau de contrôle des publications

Liste les publications en attente d'image, en échec ou en brouillon, avec la possibilité de les reprendre (avec ou sans nouvelle image), de les marquer brouillon ou de les annuler.

📈

Tableau de bord & API locale

Interface web locale (Flask) avec API : formats, planificateur, publications en attente, relance et annulation. Tout reste sur votre machine.

💾

Anti-doublon

Chaque créneau est horodaté (scheduled_for) : une publication déjà faite à un créneau n'est jamais republiée. Les échecs partiels sont repris automatiquement.

🔑

Génération de contenu

Textes (légendes, déclarations, CTA) générés avec le modèle Gemini et aperçus d'images ; mode hors-ligne de secours si l'API est indisponible.

🖼️

Gestion des médias

Génération d'images avec fonds de marque, vérification de l'ajustement du texte, conversion en formats compatibles TikTok, Facebook et YouTube.

🔒

Sécurité des secrets

Jetons conservés dans le trousseau Windows (keyring) avec repli sur un fichier .env local. Aucun secret n'est jamais écrit dans le code ni le dépôt.

🔥

Journalisation et reprise

Chaque exécution est journalisée (état, réseaux, erreurs). En cas d'échec, les publications restent en file d'attente et peuvent être relancées depuis le panneau.

🛰

Téléversement chunké TikTok

Envoi des vidéos par morceaux (8 Mo) avec interrogation du statut jusqu'à finalisation — conforme à la Content Posting API (Direct Post).

Prêt à démarrer ?

Installez l'application sur votre PC Windows et connectez vos comptes en quelques minutes.
