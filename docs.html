Documentation

Guide d'utilisation pas à pas : configuration initiale, planification, sécurité des secrets, reprise et dépannage.

1. Configuration initiale

Copiez le fichier d'exemple puis renseignez vos valeurs :

copy config.example.json config.json

Principaux réglages du config.json :

  • timezone : fuseau horaire (défaut Africa/Nairobi).
  • schedule et schedule_formats : créneaux horaires et format associé à chacun.
  • publishers : active ou désactive chaque réseau (facebook, youtube, tiktok).
  • manual_schedule : créneaux de relance manuelle.

2. Secrets et jetons

Copiez .env.example vers .env et remplissez vos clés (Gemini, jeton Page Facebook, TikTok). L'ordre de lecture est : trousseau Windows (keyring) → .env local. Les jetons ne sont jamais écrits dans le code ni le dépôt.

  • GEMINI_API_KEY : génération des textes et aperçus.
  • FACEBOOK_PAGE_TOKEN : publication sur la Page Facebook.
  • TIKTOK_CLIENT_KEY / TIKTOK_CLIENT_SECRET : app TikTok (Content Posting API).
  • TIKTOK_ACCESS_TOKEN et jetons associés : obtenus après autorisation OAuth dans l'interface.

3. Planification

Le planificateur (APScheduler) relit les formats actifs de la base de données et crée un travail par créneau. Les jobs sont persistés (SQLAlchemyJobStore) : ils survivent aux redémarrages.

Garde-fou anti-doublon : chaque publication porte un scheduled_for = dateTcréneau. Un créneau déjà publié est ignoré ; un créneau en échec partiel (partial) est relancé.

4. Panneau de contrôle

Depuis http://localhost:5000, la section « En attente (à traiter) » liste les publications en attente d'image, en échec ou en brouillon. Vous pouvez :

  • Reprendre : relance la publication du contenu stocké (option : fournir une image manquante).
  • Brouillon : passe la publication en brouillon sans publier.
  • Annuler : clôt définitivement la publication.

5. Dépannage

SymptômeCause probable / solution
La publication reste « en attente »Image manquante ou échec réseau. Ajoutez une image via « Reprendre ».
TikTok n'accepte pas la vidéoVérifiez le privacy_level (SELF_ONLY en test) et le drapeau AIGC (is_aigc).
Token expiréRefaites l'autorisation OAuth depuis l'interface.
Créneau ignoréLe garde-fou anti-doublon l'a déjà traité. Consultez le journal (Logs/).
