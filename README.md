# opencode auto post vpc — site officiel

Site statique (GitHub Pages) officiel de l'application de publication automatique
des vidéos de la page « Voix de Prospérité en Christ » vers TikTok, Facebook et YouTube.

- **Site en ligne** : https://paterne01.github.io/vpc-pages/
- **Application (code source)** : https://github.com/Paterne01/voix-de-prosperite-en-christ

## Maintenance

- Le méta-tag `tiktok-developers-site-verification` doit rester présent sur **chaque** page HTML.
- Le fichier de vérification de domaine TikTok (`tiktok*.txt`) ne doit jamais être supprimé.
- Styles partagés : `assets/style.css` ; scripts : `assets/main.js`.

Publier : pousser sur `main` (GitHub Pages publie automatiquement).
